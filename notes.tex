\section{Notes}
\label{sec:notes}
Working notebook. Keep child files in \texttt{notes/} and pull them in with
\verb|\input{notes/<name>}|; the dependency closure picks them up from the
build record, so a change in a child bumps this document and not the paper.

This is a cite example\cite{example2024}: the bibliography is shared with
\texttt{main.tex}, only its rendering differs.

\begin{equation}
  \Braket{\psi | \bm{H} | \psi} = \sum_{n} E_n \left| c_n \right|^2 .
\end{equation}

The revision markup from \texttt{styles/common.tex} works here as well:
\sh{author edit}, \ch{collaborator edit}, \rev{reviewer response},
\remove{deletion}.
